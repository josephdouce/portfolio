Tenant Guard

If you work across two Microsoft 365 tenants, sooner or later you'll create a flow, share a file or deploy a Power Platform solution in the wrong one. Tenant Guard colour-codes each Edge profile by tenant, and blocks you or warns you the moment a page belongs to the other tenant.

Always know where you are

Each profile gets a coloured strip across the top of every Microsoft page, a tenant name pill in the corner, and a badge on the toolbar icon.

How it detects the wrong tenant

  • Sign-in pages: catches you picking or typing an account from the other tenant's domains before the sign-in completes.
  • SharePoint and OneDrive: recognises the other tenant's site names, including -my and -admin hosts.
  • Guest links: decodes nested and encoded URLs to find the other tenant's ID or domain, which catches guest links into Teams, Power Apps, Azure and Entra.
  • CLI sign-ins: remembers the URL a sign-in flow started from. "Copy link for the other profile" then lets tools like pac auth finish in the right browser.

How it's built

Content scriptRuns at document_start on Microsoft cloud domains and draws its UI in a closed shadow DOM, so pages can't restyle or interfere with it.
Service workerKeeps the toolbar badge in sync with the profile's tenant.
Private by designOnly uses the storage and activeTab permissions. Settings stay in the profile, and nothing is sent anywhere.
