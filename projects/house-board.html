House Board

The family noticeboard on everyone's phone: recurring chores with a log of who did what, the kids' daily job rota, and a shared shopping list that scans barcodes and suggests Tesco products with prices. Any change appears on every signed-in phone in the house straight away.

What it does

  • Chores repeat every so many days, weeks or months, or on set weekdays. The board shows what's due, by whom it was last done, and a log that can be corrected or undone.
  • Kids' rota rotates the daily jobs (dishwasher, setting the table…) between the children, and they tick them off themselves.
  • Shopping list learns barcodes as you scan them, matches items to a Tesco catalogue for name suggestions and expected prices, and keeps an estimated basket total.
  • Households: anyone can set one up and invite the people they live with. Owners can rename the household, remove members or hand over ownership. Each household's data is kept completely separate on the server.

How it's built

Front endA single installable PWA page in plain JavaScript, designed for one-handed use on a phone.
Back endA small Node.js server with no framework. It stores data as documents grouped into collections, and each household is isolated.
Real-timeServer-Sent Events push every change to the household's other devices instantly.
StoragePostgreSQL in production, and a SQLite file for local development, so you can try it with nothing installed.
AccountsSign-up confirmation and password-reset emails via Resend, rate limiting, and an admin view that can pause any household.
DeliveryTests run on GitHub Actions, then a self-hosted runner deploys to the home server with an automatic rollback.
