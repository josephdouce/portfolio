Bookbag Buddy

Times tables, number bonds and spellings for primary schools, practised little and often. Pupils practise on a tablet or phone, teachers set the week's work and see who needs help, and parents follow along at home.

Pupils

No email or password: a pupil enters the class code, taps their name and types a 4-digit PIN. The home screen shows only this week's work. Times tables use an on-screen number pad and a timer, so a fact only counts as fluent when it's answered within 6 seconds. Wrong answers show the correct fact and come back a few questions later.

Teachers

Teachers sign up with their school's invite code, create classes and set each week's tables and spellings, either in the app or by dropping a text file into a folder. Results show accuracy, speed and the latest test score for each pupil, the class's trickiest items, and a full 12×13 grid of every fact for each child. A calendar and messages tab replaces the paper letter home.

Parents

Parents add each child with the code from their login card, then see this week's work, recent mistakes, messages and school dates. Dates sync to Apple, Google or Outlook calendars through a private subscribe link. Parents can turn on push notifications for messages, new work, reminders the evening before a date, and a gentle nudge after three days without practice. Nothing is sent between 8pm and 7am.

How the learning works

Every fact and word sits in a Leitner-style "box" from 0 to 6 for each pupil. A correct answer on a due item moves it up a box, and the next review comes after 1, 2, 4, 7, 14 or 30 days. A wrong answer drops it back to the start. Extra practice before an item is due is recorded but doesn't move it up, so something only becomes secure after being right on separate days. Spelling practice can only take a word so far: only the test moves words to secure.

How it's built

Front endOne framework-free JavaScript PWA. It installs on Android, iOS and desktop and works well on a cheap tablet.
Back endNode.js with Express and PostgreSQL. On a laptop it uses an embedded copy of Postgres (PGlite), so trying it needs no setup.
Securityscrypt-hashed passwords, hashed session tokens, PIN lockout after 5 tries, and database-level checks that stop data crossing between schools.
IntegrationsWeb Push (VAPID), iCalendar feeds, Resend for email, and the DfE school directory (GIAS) for adding schools.
DeliveryGitHub Actions runs the test suite, then a self-hosted runner deploys to a mini PC through a Cloudflare tunnel, rolling back automatically if the health check fails.
Built to scaleA stateless app server and a database chosen by URL, so moving to managed Postgres needs no code changes.
